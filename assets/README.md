# Original WAM identity

`wam-coin-original.png` is the original 400 × 400 PNG attached by the owner
on 14 October 2026. It is stored verbatim, with no crop, recoloring, replacement
or generated artwork. SHA-256:
`1b189fb54969e6229a984f27ade4524bf4c327bb447d6da9fdbef3a8c2c30989`.

`wam-wallet.icns` is derived only from that PNG using Apple's `sips` (16, 32,
128, 256, 512 and corresponding @2x sizes) and `iconutil -c icns`.
Larger sizes are resampled from the supplied 400-pixel source. SHA-256:
`dc8c4de2aeac66e062ac530b2a462e639646e02b3cfe5a7ba6f8c4bd8f571fb7`.

The app uses the original PNG for Qt branding and the ICNS for Finder/Dock.
The frozen self-check requires both pinned hashes and the bundle's icon plist.
